# Agapay FAQ content

The runtime FAQ is `CHAT_FAQ` in `packages/shared/src/chat.ts`, reused by the static widget and the read-only FAQ tool. Keep one runtime source rather than duplicating answers here.

It describes the implemented account-free request flow, reference-plus-email private tracking, donor email confirmation, personnel collection scheduling, and personnel eligibility decisions. A preferred donation date is not a confirmed appointment, and submission is not approval.

Organisation review of FAQ wording, local emergency guidance, and the widget privacy notice is still required before production acceptance. No organisation approval or live provider verification is claimed by the implementation.
